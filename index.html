How to estimate your monthly API cost

Start with one request, not a whole month. Take a typical prompt and the answer it gets, count both in tokens (switch the input fields to words if that is how you wrote them), and multiply by the requests you expect in a day, then by 30.

Input and output are priced separately, and output is the expensive side: across the models below it costs three to ten times more per token. A short prompt that produces a long answer often inverts a budget written the other way round.

Two discounts are missing from the standard rates above. Batch APIs, for work that can wait a day, typically halve the price. Prompt caching, for a repeated system prompt or a fixed document, takes 50–90% off the input price of the cached part. With either switched on, the real bill lands below this estimate.

Frequently asked questions

What is a token?

A token is a small chunk of text a model reads or writes. In English, one token is roughly 4 characters or about 0.75 words, so 1,000 words is around 1,330 tokens. Code and non-English text usually use more tokens per word.

How is LLM API cost calculated?

Cost = (input tokens ÷ 1,000,000 × input price) + (output tokens ÷ 1,000,000 × output price), multiplied by your number of requests. Output tokens usually cost 3 to 10 times more than input tokens, so long answers add up fast.

What is prompt caching and how does it lower cost?

Prompt caching lets providers reuse a repeated prompt prefix, such as a long system prompt or document, at a steep discount, often 50% to 90% off the input price. This calculator uses standard rates, so your real bill may be lower if you cache.

Why can my real bill differ from this estimate?

Real bills depend on tokenizer differences between models, conversation history resent with each request, tool calls, reasoning tokens, batch discounts, caching, long-context surcharges and price changes. Treat this as a planning estimate.

Are the default prices up to date?

Defaults are list prices per 1M tokens at the time of writing, and providers change them often. Every rate in the table is editable, so check the provider's pricing page and adjust.

How can I reduce my AI API costs?

Use a smaller model for simple tasks, shorten prompts, cap output length, enable prompt caching, use batch APIs for non-urgent work, and route easy requests to cheaper models.

How do I estimate tokens for a chat app that resends history?

Each turn resends the conversation so far, so input tokens grow with every turn and the total for one long conversation grows faster than its length. Measure the usage of a real conversation instead of multiplying a single request by the number of messages.
